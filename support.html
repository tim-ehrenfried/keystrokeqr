Troubleshooting

  • iPhone can't find the Mac. Make sure both devices are on the same Wi-Fi, that you allowed the Local Network permission on the iPhone, and that any VPN on the Mac is off (it can block local discovery). Check your Mac's firewall allows incoming connections for KeystrokeQR Host.
  • The Mac doesn't type. Grant the Accessibility permission: System Settings → Privacy & Security → Accessibility → enable "KeystrokeQR Host". If you rebuilt or reinstalled the app, remove the old entry and add it again.
  • The pairing code doesn't work. Each code is valid for 90 seconds and one attempt. If it expires, the Mac shows a fresh code automatically — just enter the new one.
  • Text gets jumbled with long content. On the Mac, open the KeystrokeQR panel and lower the typing speed to "Slow".
